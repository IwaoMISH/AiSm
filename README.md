# AiSm ( Minimum 版 ファイルマージツール )

## 概要
AiSm は、ドラッグ＆ドロップした複数のテキストファイルを結合し、日時を付与したファイル名で一時フォルダに出力するシンプルな Win32/MFC ツールです。

## ビルド方法
本パッケージには実行ファイルは含まれておりません。
お使いの環境に合わせて以下のプロジェクトファイルを開き、ビルドを行ってください。

* **Visual C++ 6.0:** `AiSm.dsp` / `AiSm.dsw`
* **Visual Studio 2005 - 2008:** `AiSm.vcproj` / `AiSm05.sln`
* **Visual Studio 2010 - 2026:** `AiSm.vcxproj` / `AiSm10.sln`

## 使い方
1. ビルドして生成された `AiSm.exe` を起動します。
2. 結合したいファイルをダイアログ上にドラッグ＆ドロップします。
3. **[マージ]** ボタンを押すと、結合処理が実行されます。
4. 完了後、出力先フォルダ（`%TMP%\AiSm_M\`）が自動的に開かれます。

## 注意事項
* バイナリファイル（NULL文字を含むファイル）は、安全のため結合対象から除外されます。
* 本ツールは Microsoft Visual C++ で開発されています。
