【概要】
AiSm は，ドラッグ＆ドロップした複数のテキストファイルを結合し，
日時を付与したファイル名で一時フォルダに出力するシンプルなツールです．

【ビルド方法】
本パッケージには実行ファイルは含まれておりません．
Visual Studio または Visual C++ 環境にて，プロジェクトファイル（AiSm.sln / AiSm.dsw）
を開き，ビルドを行ってください．

【使い方】
1. ビルドして生成された AiSm.exe を起動します．
2. 結合したいファイルをダイアログ上にドラッグ＆ドロップします．
3. [マージ] ボタンを押すと，結合処理が実行されます．
4. 完了後，出力先フォルダ（%TMP%\AiSm_M\）が自動的に開かれます．

【注意事項】
・バイナリファイル（NULL文字を含むファイル）は，安全のため結合対象から除外されます．
・本ツールは Microsoft Visual C++ で開発されています．
